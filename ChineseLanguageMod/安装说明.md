# Death Trash 简体中文汉化 MOD — 安装说明

适用于 Death Trash 抢先体验版(基于 v0.14.6.1 导出文本制作)。

## MOD 内容

```
ChineseLanguageMod\
├── mod.manifest      模组信息(必需)
├── chinese.tsv       汉化文本(必需,全量 6878 条)
├── icon.png          模组列表图标
└── 安装说明.md       本文件
```

---

## Windows 安装位置

MOD **只能**放在系统的存档数据目录下,**不是**游戏安装目录:

```
C:\Users\<你的用户名>\AppData\LocalLow\Crafting Legends\Death Trash\Mods\ChineseLanguageMod\
```

### 快速到达

1. 按 `Win + R`,输入:

   ```
   %userprofile%\AppData\LocalLow\Crafting Legends\Death Trash\Mods
   ```

   回车即可打开 Mods 文件夹(`AppData` 是隐藏文件夹,手动找请先开启"显示隐藏项目")。

2. 把整个 `ChineseLanguageMod` 文件夹复制进去。注意 `mod.manifest` 必须在 `ChineseLanguageMod` 根目录下,不要套第二层文件夹。

### 目录结构(正确示例)

```
...\Crafting Legends\Death Trash\
├── Mods\
│   ├── ChineseLanguageMod\   ← 汉化 MOD 放这里
│   │   ├── mod.manifest
│   │   └── chinese.tsv
│   ├── ExampleMod\           ← 游戏自带示例,可无视
│   └── LanguageData\         ← 游戏导出的语言文件
└── ExportedGameData\
```

### 启用

1. 启动游戏,主菜单进入 **Mods**;
2. 列表中找到 **Simplified Chinese Translation**,启用(enable);
3. 若界面仍是英文,检查游戏的语言设置是否已切到由 MOD 提供的中文。

---

## 卸载

删除 `Mods\ChineseLanguageMod\` 文件夹,或在游戏内 Mods 菜单停用即可。该 MOD 只替换文本,不影响存档;停用后游戏恢复英文,存档可继续使用。
